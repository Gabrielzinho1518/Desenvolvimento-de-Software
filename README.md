# 💻 Desenvolvimento de Software

Repositório destinado às atividades, projetos e trabalhos desenvolvidos na disciplina de **Desenvolvimento de Software**, utilizando principalmente a linguagem **Java**.

---

## 📚 Sobre o projeto

Este repositório reúne os códigos desenvolvidos durante a disciplina, incluindo exercícios, atividades práticas e projetos relacionados ao desenvolvimento de software.

Os projetos abordam conceitos importantes de programação, como:

- ☕ Programação em Java
- 🧩 Programação Orientada a Objetos (POO)
- 🖥️ Interfaces gráficas com Java Swing
- 📁 Manipulação de arquivos
- 🔄 Serialização de objetos
- 🌐 Comunicação entre aplicações
- 🔌 Sockets
- 🏗️ Estruturação e organização de projetos
